# Quality pass (2026-10-18)

**Scope:** every public page and every student page.

**Checks:**
- Lighthouse 13.5 (mobile, simulated throttling) on a local production build (`next build && next start`). nuevo.celstv.com can't be reached from the build sandbox.
- axe-core 4.11 (WCAG 2.0/2.1 A and AA) at 360 px and 1440 px, as a signed-out visitor and as a test student.
- A crawler that follows every internal link and records the HTTP status and console errors.

**Targets:** performance 85+ and accessibility 95+ (spec).

## What was fixed

### Performance

- **Home rendered the whole page every 2.6 s.** The rotating hero word and the intro tags are state on the board component, so each change re-rendered all 10 sections, taking 120–260 ms on a mid-range phone.
  - Everything below the hero is now wrapped in a memoized `<Keep>` that only updates when its own state changes.
  - Total blocking time fell from about 520 ms to 100–170 ms.
  - The goal picker, price tabs and mini quiz were re-tested and still work.
- **Home setup work on load.**
  - The board's setup (intro sequence, Ana's path, voices) now waits for an idle moment, so it no longer delays the first paint.
  - Ana's path measurement now samples every 8 px instead of every pixel, then refines the result.
  - The sections below the fold use `content-visibility: auto`.
- **The root layout asked Supabase for the user on every page.**
  - It existed only so the offline sync could know the user.
  - `OfflineSync` now reads the session in the browser.
  - This saved one round trip on every request.
- **Public pages read the database on every visit.**
  - The root layout reads the language cookie, so every route renders on demand and `revalidate = 3600` had no effect.
  - The prices (`products`) and the CelsTV episode list are now cached for an hour with `unstable_cache`, using a signed-out client (`src/lib/supabase/public.ts`).
  - Response time on `/celstv` dropped from 1.2 s to 0.3 s.
  - A price change in `products` shows up on the site within an hour.
- **Student home layout shift (CLS 0.25).**
  - The "Descargar app" card appeared after loading and pushed the page down.
  - It is now rendered on the server.
  - "Ahora no" is stored in a cookie instead of `localStorage`.
  - The installed app hides the card with CSS (`display-mode: standalone`).
- **Episode artwork.**
  - The full-size PNGs from Storage are now served through `next/image`, resized and converted to modern formats.
  - The main image on the course and episode screens loads first.
- **Loading state.** Student pages had none, so navigation looked frozen while the server worked. `src/app/app/loading.tsx` now shows a skeleton inside the app shell.

### Accessibility

- **Landmarks.** Each website board now wraps its content in `<main>`.
- **Contrast below 4.5:1.** Colors are only darkened where text sits on them.
  - Pink buttons with white text (`#F5178C`/`#F20174`, 3.9–4.2:1) → `#D6006A` (5.2:1), hover `#B0005A`. This covers:
    - `btn-primary`;
    - Cuenta;
    - the purchase flow;
    - the parts' buttons;
    - "Descargar app";
    - the 404 page;
    - the legal page header;
    - the "En curso" badge;
    - the Home "APRENDE" tag.
  - The pink stays as the decorative accent.
  - Program buttons now use their own `fill`/`onFill` colors (`brand.tsx`):
    - CelsBSNS: cyan with dark text;
    - CelsGLOBAL: sage `#4F6F60`.
  - Website boards:
    - CelsTV "Observa" badge;
    - CelsBSNS "Reading"/"Writing" chips;
    - CelsGLOBAL month tabs and program colors (darkened just enough to reach 4.6:1 on ivory);
    - CelsUS hint text and the `#6B7A90` gray.
  - App:
    - Progreso level chips and streak label;
    - CelsGLOBAL route stage labels;
    - BSNS "En curso" chip;
    - active tab label in the bottom bar.
- **The accessible name didn't contain the visible text (WCAG 2.5.3).** Fixed on:
  - the language button ("EN");
  - the Home tags;
  - the CelsBSNS week tabs;
  - Cuenta's photo link;
  - the unit buttons;
  - the CelsCards card;
  - the CelsBook "ES" toggle.
- **CelsCards hid the answer badly.** The hidden face of a card was still read out, so screen-reader users heard the answer before flipping. The hidden face is now `aria-hidden`.
- **Progress bars with no name.** Labels were added to:
  - the part header;
  - the civics exam;
  - the CelsGLOBAL route;
  - the evaluation;
  - the episode download.

## Still open

- **Course page and episode screen (84–87).** Server response time is 1.5–1.9 s here: these pages make several Supabase queries per visit, and this sandbox reaches Supabase through a proxy. On Vercel (closer to Supabase) they should pass 85. If they don't, the next step is to merge the queries in `src/lib/course-page.ts` into one RPC.
- **Largest paint on public pages is about 3.7–4 s** under Lighthouse's slow-4G simulation. It comes from response time plus fonts and CSS. Making the marketing pages static would need the root layout to stop reading the language cookie (for example, `/en` routes). Not done: it changes how the language toggle works.
